# 💰 DompetKu - Personal Finance Tracker

Aplikasi pelacak keuangan pribadi berbasis web sederhana yang menggunakan **JavaScript Vanilla** dan **LocalStorage** untuk membantu mencatat pemasukan dan pengeluaran secara langsung tanpa server backend.

## 🚀 Fitur Utama
- **CRUD Transaksi**: Tambah dan hapus riwayat transaksi dengan cepat.
- **Kalkulasi Otomatis**: Menghitung total saldo, total pemasukan, dan total pengeluaran secara real-time.
- **Persistent Data**: Data tersimpan di browser via `LocalStorage` (tidak hilang saat di-refresh).
- **Format IDR**: Tampilan angka disesuaikan dengan format Rupiah Indonesia.

## 🛠️ Teknologi yang Digunakan
- **HTML5**: Struktur komponen antarmuka.
- **CSS3**: Styling responsif dengan Flexbox & Gradients.
- **JavaScript (ES6)**: Logika kalkulasi, manipulasi DOM, dan manajemen LocalStorage.
